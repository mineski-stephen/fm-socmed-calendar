Google Drive image probe

Reads the live tracker and tries to render every asset as a plain <img>, the way a static page would have to. Direct files come from Files Chip URL; folder contents come from the Drive Folder File List column, which is what makes folders workable without the Drive API. Nothing here is part of the site — index.html does not link to it and nothing imports it.

Read this before trusting the result.

If this browser is signed in to a Google account that can already see these files, they may load for you and for nobody else. The number that matters is the one you get in a private / incognito window, signed out — that is what a client, or anyone opening the hosted page, will actually get. Run it both ways and compare.
